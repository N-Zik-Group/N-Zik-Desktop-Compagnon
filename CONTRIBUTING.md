# 🤝 Contributing to N-Zik-Desktop-Compagnon

## 🛠️ Improve the project

Pull requests are welcome. Describe the problem or improvement and how you verified the change. 



## 📜 Clone the repo

    git clone -b main --single-branch --recursive https://github.com/N-Zik-Group/N-Zik-Desktop-Compagnon.git

## ✅ Verify your changes

Use the Gradle wrapper and the README setup instructions. For pairing or playback changes, describe the desktop OS, Android version and verification steps.

## 📬 Open a pull request

Keep the change focused and link the related issue when there is one. Include verification steps and screenshots for visual changes when applicable.
