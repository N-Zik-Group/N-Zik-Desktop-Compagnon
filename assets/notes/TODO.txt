Features
- Synced appearance (option "Use the phone's appearance"): the phone exposes a read-only whitelist of UI preferences (light/dark mode, palette and accent, dynamic color from artwork, roundness, font, player and seek bar styles…) through contract 1.2 (e.g. `GET /api/v1/appearance` + a WS `appearanceChanged` message); the Compagnon applies them live when the option is on and keeps its own local settings when it is off. The PC never writes the phone's preferences, and no secret or non-UI setting is exposed. A preference only matters once the matching UI piece is copied, so it grows with the copied screens. Audio (follow-ups from story 12)
- The audio cache is filled by a second download of the signed URL beside the player's own stream (double transfer of the current track); a shared download feeding both would halve it.
- A phone-side seek smaller than 0.5 s, and a drift under 1.5 s, are not followed (tolerance of the story).
- An expired / invalid URL is detected from a VLC error then a HEAD probe; a HEAD answer has no body, so a `403` is read again as a one-byte GET to get its code.
- No media keys and no tray (story 12 non-goals).
- Packaging trial (opt-in): `gradlew test -PvlcTrial=<folder of audio samples>` plays every sample from a file and over HTTP with the embedded runtime and prints the libvlc modules used.
