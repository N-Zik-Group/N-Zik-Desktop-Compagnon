# Changelog Convention (N-Zik Desktop Compagnon)

To maintain a clean and consistent project history, for the 'Done.txt' file:
each entry must be detailed — one-line summaries are not enough. Follow the format below.

---

## Entry Format

Each entry uses this structure:

```
<keyword>(<scope>): <short summary> (issue/commit ref if any)
  - <technical detail 1: what changed, in which file/function>
  - <technical detail 2: why it was needed / what bug it fixes>
  - <technical detail 3: side effects, edge cases handled>
  - <...as many sub-bullets as needed to fully describe the change>
```

- `<scope>` = the affected module/area (e.g. `pairing`, `player`, `library`, `ui`, `build`)
- Sub-bullets should reference concrete file names, function names, or class names when relevant
- Include issue/PR links when available: `(issue https://github.com/N-Zik-Group/N-Zik-Desktop-Compagnon/issues/123)` or commit hash `` (`9f35d2c8e2`) ``
- If a fix touches multiple files or has multiple root causes, list each as its own sub-bullet
- Prefer explaining root cause + fix, not just the symptom

---

## Standard Keywords

### Hotfix:
For urgent patches that fix a critical bug or regression in a previously released version, outside of the normal release cycle.

```
Hotfix:
- fix(startup): resolve app crash on launch (issue https://github.com/N-Zik-Group/N-Zik/issues/701)
  - Missing Room database migration between v12 and v13 caused a fatal crash on first launch
  - Added `Migration12to13` handling the new `lyrics_karaoke` table
  - Verified against a clean install and an upgrade path from v1.4.2
```

---

### Added:
For any new feature, screen, or capability added to the application.

```
Added:
- feat(visualizer): add adjustable line thickness (issue https://github.com/N-Zik-Group/N-Zik/issues/588)
  - New `lineThicknessKey` preference, exposed in the Visualizer settings menu via `EnumSettingEntry`
  - Range 1–5dp, default 2dp, applied live in `AudioWavePill`
  - Persisted in DataStore alongside existing visualizer prefs
```

---

### Changed:
For changes in behavior, design, or logic of an existing feature.

```
Changed:
- change(ui): default thumbnail roundness 12 → 20 (issue https://github.com/N-Zik-Group/N-Zik/issues/612)
  - Updated `ThumbnailShape` default in `Theme.kt`
  - Applies to Home, Search, and Player screens; user overrides in settings are unaffected
```

---

### Improved:
For minor UI, UX, or performance enhancements that are neither entirely new features nor outright bug fixes.

```
Improved:
- improve(visualizer): buttons squeeze dynamically on round thumbnails
  - `PlayerItemMenu` row now measures thumbnail shape and adjusts button spacing via `Modifier.weight`
  - Prevents button overlap previously seen on circular thumbnail styles
```

---

### Fixed:
For any bug fixes or crash resolutions.

```
Fixed:
- fix(lyrics): prevent FOREIGN KEY constraint crash on fast lyric APIs (issue https://github.com/N-Zik-Group/N-Zik/issues/639)
  - Created `saveLyricsSafe` helper in `LyricsFetcher.kt` to catch `SQLiteConstraintException`
  - Added a 5-second async retry to let the background player persist the parent `Song` entity first
  - Replaced all raw `Database.asyncTransaction { lyricsTable.upsert(...) }` calls with `saveLyricsSafe(...)`
```

---

### Refactor:
For internal code changes that do not alter existing external behavior or functionality, but improve the code structure, readability, or maintainability.

```
Refactor:
- refactor(visualizer): extract control buttons into their own composable
  - Moved inline button row out of `VisualizerScreen` into `VisualizerControls.kt`
  - No behavior change; reduces `VisualizerScreen` from 480 to 310 lines
```

---

### Removed:
For features or options that have been intentionally taken out of the application.

```
Removed:
- remove(player): drop legacy video player component (issue https://github.com/N-Zik-Group/N-Zik/issues/598)
  - Deleted `LegacyVideoPlayer.kt` and its DataStore flag `useLegacyPlayerKey`
  - All video playback now routes through `ExoVideoPlayer`
```

---

### Deprecated:
For features that are still present but are marked to be removed in a future update.

```
Deprecated:
- deprecate(visualizer): old visualizer style, removal planned for v2.0
  - Marked `LegacyVisualizerStyle` with `@Deprecated` annotation
  - Settings entry hidden behind a "Legacy" toggle for now
```

---

### Other:
For miscellaneous updates, documentation changes, or dependency bumps that don't neatly fit into the above categories.

```
Other:
- chore(deps): update Gradle plugins to latest stable
  - AGP 8.6.0 → 8.7.1, Kotlin 2.0.20 → 2.0.21
  - No source changes required, build verified on CI
```
